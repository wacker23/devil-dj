# Devil-DJ

A Windows DJ application in C++20 / JUCE 8: a full DJ engine (decks, library, analysis, cues, loops, FX, sampler, stems, recording, Automix), a built-in Beat Maker, and a live-coding Code Beat deck — all playable without a DJ controller.

- New here? Read `START_HERE.md`.
- Working on the code (human or Claude Code)? Read `CLAUDE.md`, then `docs/PLAN.md`.
